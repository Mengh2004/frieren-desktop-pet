芙莉莲 · 旅途小憩
Windows 透明动态桌宠 | v1.1

启动
双击 Frieren.exe 即可。无需安装 Python、Node 或额外软件，无需联网和 API Key。
程序使用 Windows 自带的 .NET Framework 4.8。重复启动不会出现多只桌宠。

交互
• 按住角色拖动：用鼠标左键把她移到屏幕上的其他位置，松开后自动记住位置。
• 单击角色：摸摸头，露出开心表情并飘出小爱心。
• 双击角色：挥动法杖，出现魔法光点。
• 右键角色：打开菜单，可看书、打盹、调整大小、暂停、隐藏或退出。
• 托盘图标：右键显示/隐藏或退出；双击找回隐藏的角色。
• 单击在松开鼠标后稍等系统的双击识别时间；拖动不会触发摸头或施法。
• 右键菜单和托盘菜单中的“回到右下角”可恢复初始位置。

动画与位置
待机有柔和呼吸和眨眼，间隔一段时间会安静地看书或打盹。
首次启动在主屏幕工作区右下角，任务栏上方；按住左键可以拖动，松开后停留在新位置，不会自行散步。
重新启动时会恢复上次拖动的位置；屏幕布局改变时会将角色放回可见的工作区。
表情变化和呼吸仅在固定窗口内部发生。默认置顶，可在右键菜单中取消。
透明处可以点到下方应用，点角色不会抢走正在输入的应用的键盘焦点。
支持小巧、标准、大一点三档大小，位置、大小和置顶偏好保存在 settings.json。
未设置开机启动，没有声音、网络请求、屏幕读取或聊天服务。

重新构建（Windows PowerShell）
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
修改源代码后请先通过右键菜单退出正在运行的桌宠，再构建。

自检
.\Frieren.exe --self-test .\tests
自检检查透明图集、动画状态、拖动和点击区分、屏幕边界、三档定位及新旧配置兼容和位置保存。
需要记录交互位置时，可运行：
.\Frieren.exe --diagnostics .\tests\interaction.log

如果没有看到角色
先查看系统托盘的隐藏图标区，双击芙莉莲图标即可恢复显示。
程序异常时会在同目录生成 error.log。
